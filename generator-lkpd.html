Keamanan dan privasi — baca sebelum menghubungkan:
  • API Key tidak ditanam di GitHub atau file website. Setelah uji koneksi berhasil, kunci disimpan sementara di sessionStorage tab ini dan dikirim langsung ke Google melalui header HTTPS. Gunakan hanya pada perangkat pribadi; kunci tetap dapat dilihat oleh orang yang menguasai browser/Developer Tools atau ekstensi browser.
  • MathSMP memakai Gemini Interactions API dengan store: false agar interaksi tidak disimpan sebagai riwayat yang bisa dipanggil kembali. Ini bukan jaminan penghapusan semua pemrosesan data oleh penyedia.
  • Pada tier gratis Gemini, Google menyatakan konten yang dikirim dapat digunakan untuk meningkatkan produk. Jangan masukkan nama/NISN, nilai, data pribadi siswa, atau dokumen/ informasi rahasia. Periksa kebijakan dan tier akun sebelum mengirim data.
  • Model tertentu mungkin memiliki kuota gratis, tetapi ketersediaan, batas pemakaian, dan ketentuan biaya dapat berubah mengikuti akun Google. Periksa ketentuan harga resmi Gemini API.
